# Open Graph Image Requirements

## Create an OG Image: og-image.jpg

For optimal social media sharing, create an image with these specifications:

### Dimensions
- **Recommended**: 1200 x 630 pixels
- **Aspect Ratio**: 1.91:1
- **Format**: JPG or PNG (JPG preferred for smaller file size)

### Content Suggestions
Include:
- Your name: "Junaidh Haneefa"
- Your title: "Full Stack Developer"
- Key technologies: Flutter, Kotlin, React
- Professional photo (optional)
- Your website: junaidh.me
- Clean, professional design matching your portfolio colors

### Tools to Create
1. **Canva**: Use their Social Media template (1200x630)
2. **Figma**: Free design tool with templates
3. **Adobe Express**: Quick social media templates
4. **Online OG Image Generator**: Various free tools available

### File Location
Place the final image at:
```
/public/images/og-image.jpg
```

### Testing
After creating the image, test how it looks on social media:
- **Facebook**: https://developers.facebook.com/tools/debug/
- **Twitter**: https://cards-dev.twitter.com/validator
- **LinkedIn**: Share in LinkedIn and check preview

### Current Fallback
The system currently references `/images/og-image.jpg`. If not present, social media platforms will use the site's default behavior.
