# Brand mark

The mark is a JH monogram for Junaidh Haneefa. The J and the H share one stem, and the last stroke of the H is a text cursor in the accent colour: flat ends, slightly taller than the letters. It reads as initials first and as "a developer, mid-line" second.

- mark-dark.svg: letters #f2f1ec, cursor #2fbf7f. Use on dark backgrounds.
- mark-light.svg: letters #111111, cursor #0b7a4b. Use on light backgrounds.
- mark-mono-dark.svg, mark-mono-light.svg: one colour, for stamps and single-ink print.
- mark-small-dark.svg, mark-small-light.svg: a heavier cut for 32px and below.
- tile.svg: the mark on an #f2f1ec rounded square. App icon, header tile.
- tile-accent.svg: the mark on an #2fbf7f rounded square. Social avatars.
- wordmark-dark.svg, wordmark-light.svg: mark with "Junaidh Haneefa" in Manrope ExtraBold. The text is live, so the font must be installed or the file outlined before sending to print.
- icon-512.png, avatar-512.png: raster tiles for stores and profiles.
- ../favicon.svg, ../favicon-32.png, ../apple-touch-icon.png: the small cut on the ink tile.

## PNG images

Ready-made images are in `png/`, with `png/preview.png` as an overview. Marks, tiles, squares and rounds are 1024px; "dark" and "light" always name the background the image is for.

- mark-dark, mark-light, mark-mono-dark, mark-mono-light: the mark alone on a transparent background.
- mark-small-dark, mark-small-light: the heavier cut at 128px, transparent.
- tile-ink, tile-accent, tile-dark, tile-light: rounded app-icon tiles with transparent corners.
- square-ink, square-accent, square-dark, square-light: full-bleed squares, for platforms that crop the image themselves.
- round-ink, round-accent, round-dark, round-light: circles with a transparent surround.
- wordmark-dark, wordmark-light: mark and name on a transparent background.
- wordmark-on-dark, wordmark-on-light: the same with padding and a solid background.
- stacked-on-dark, stacked-on-light: mark above the name and role, 1200px square.
- favicon-16, favicon-32, favicon-48: the small cut on the ink tile.

The wordmark and stacked images have the name set in Manrope already, so they need no font.

Clear space: at least the cursor's width on every side. Minimum size: 16px for the small cut, 40px for the regular cut, 140px wide for the wordmark. Do not rotate, outline or recolour the letters, round the cursor's ends, or put the mark on a photo. On screen the cursor may blink; in print it is solid.
